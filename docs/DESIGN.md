# Bayt design brief

Arabic-first literary workshop. Editorial minimalism: warm paper, dark ink,
restrained copper, Amiri for verse and IBM Plex Sans Arabic for controls.
The composition desk and manuscript have different visual weights. Mobile is
one column; larger screens put controls beside the poem. No invented metrics.

Applied source: https://github.com/plugin87/ux-ui-agent-skills
Read design-screen, design-doctrine, RTL guidance, token spacing and aesthetic
systems. Source kit was retrieved outside the application, not made a runtime
dependency. Theme variables live in frontend/src/style.css. This is an initial
implementation, not a claim of passing the kit's full design-system gates.

Generation failure must keep existing output visible. A sample is identified
as Imru' al-Qais, never presented as generated work. Machine-accepted means
PyArud accepted meter and selected rawi; it is not expert certification.
